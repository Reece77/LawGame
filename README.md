# Partner Track

A single-player, turn-based law firm management game for personal use: found a small firm in January 2005 and grow it into a global partnership over a 30-year campaign. Built on Tech Startup Tycoon's engine by a selective transplant (`docs/adr/PT-0001-code-sharing.md`).
